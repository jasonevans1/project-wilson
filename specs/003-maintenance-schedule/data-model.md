## Enum: `RecurrenceUnit`

**File**: `app/Enums/RecurrenceUnit.php`
**Type**: Backed string enum

| Case | Value | Description |
|------|-------|-------------|
| `Daily` | `'daily'` | Recurs every N days |
| `Weekly` | `'weekly'` | Recurs every N weeks |
| `Monthly` | `'monthly'` | Recurs every N months |
| `Yearly` | `'yearly'` | Recurs every N years |

**Carbon mapping**:
- `Daily` → `$date->addDays($count)`
- `Weekly` → `$date->addWeeks($count)`
- `Monthly` → `$date->addMonthsNoOverflow($count)` — avoids end-of-month overflow (e.g., Jan 31 + 1 month = Feb 28, not Mar 3)
- `Yearly` → `$date->addYearsNoOverflow($count)`

## State Transitions

### MaintenanceTask

```
[created] → is_active: true
              ↓ user deactivates
           is_active: false  (terminal — no reactivation in v1)
```

### MaintenanceOccurrence

```
[generated] → completed_at: null (pending)
                  ↓ user marks complete
               completed_at: <timestamp>  (terminal)
               → new pending occurrence auto-generated by MaintenanceScheduler
```

## Service: `MaintenanceScheduler`

**File**: `app/Services/MaintenanceScheduler.php`
**Purpose**: All recurrence date arithmetic and occurrence generation. No DB reads — accepts models as parameters.

**Public interface**:

```php
// Calculate the next due date from a given base date
public function nextDueDate(
    Carbon $fromDate,
    RecurrenceUnit $unit,
    int $count
): Carbon

// Generate and persist the next pending occurrence for a task
// Called after an occurrence is completed
public function generateNextOccurrence(
    MaintenanceTask $task,
    Carbon $baseDueDate
): MaintenanceOccurrence

// Generate and persist the first occurrence when a task is created
public function generateFirstOccurrence(
    MaintenanceTask $task,
    ?Carbon $startDate = null
): MaintenanceOccurrence
```

**Key rule**: `generateNextOccurrence` always uses the prior occurrence's `due_date` as the base (not `completed_at`), ensuring schedule integrity regardless of early/late completion.

## Eager Loading Strategy

All schedule queries must eager-load:
- `MaintenanceOccurrence::with(['task', 'task.asset'])`

Per-asset task queries:
- `MaintenanceTask::with(['occurrences' => fn($q) => $q->whereNull('completed_at')])`
